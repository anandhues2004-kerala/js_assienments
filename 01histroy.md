21. What happens when you type a URL in a browser?
a: When you enter a URL, the browser breaks it down, resolves the domain name to an IP address using DNS, and establishes a connection (TCP/IP or TLS/SSL) with the web server. The browser sends an HTTP request to the server, which responds with website files (HTML, CSS, JS), allowing the browser to render and display the page
